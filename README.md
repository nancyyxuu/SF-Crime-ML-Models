# San Francisco Crime Classification Using Machine Learning 
## Project Overview
Machine-learning project analyzing 800,000+ San Francisco crime observations
to evaluate multiclass classification approaches.

## Tools
Python | Pandas | Scikit-learn | Matplotlib | Jupyter

## Methodology
- Data cleaning and preprocessing
- Temporal and geographic feature engineering
- Train/test separation
- 3-fold cross-validation
- Multiclass model comparison
- Log-loss evaluation

## Models
- Categorical Naive Bayes
- Multinomial Logistic Regression
- Random Forest

## Key Finding
Multinomial Logistic Regression demonstrated the strongest out-of-sample
performance and generalizability among the evaluated models.
